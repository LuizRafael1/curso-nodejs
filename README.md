# Curso Node.js

Repositório dedicado aos meus estudos de Node.js. O código é baseado em um curso 
que estou acompanhando diretamente do youtube, sendo utilizado e modificado conforme as aulas passam, como forma de 
praticar e consolidar os conceitos aprendidos.

## Objetivo

- Aprender os conceitos básicos de Node.js
- Compreender a criação e o funcionamento de APIs e rotas
- Evoluir para o uso do framework Express
- Revisar conhecimentos de banco de dados
- Praticar métodos HTTP e operações CRUD completas
- Conectar a API a um banco de dados 
- Lidar com variáveis de ambiente e configurações sensíveis
- Testar rotas com a ferramenta Insomnia
